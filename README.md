# College Event Registration System

A full-stack web application for managing college events and student registrations.

## Project Goals

- Display upcoming college events and event details.
- Allow students to register for events.
- Manage participant lists and search for participants.
- Track event capacity and registration status.
- Provide event creation, viewing, updating, and deletion.

## Technology Stack

- Frontend: React, HTML, CSS, JavaScript
- Backend: Node.js, Express.js, REST API
- Database: MongoDB
- Version Control: Git and GitHub
